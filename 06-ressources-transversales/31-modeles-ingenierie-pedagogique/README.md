# 31 — Modèles d’ingénierie pédagogique

Découvrir les principaux modèles et approches de l’ingénierie pédagogique, comprendre leur fonctionnement et identifier dans quelles situations les utiliser.

## Notions à explorer

- ADDIE : comprendre les cinq phases de conception et de développement d'une formation.
- SAM (Successive Approximation Model) : découvrir une démarche de conception pédagogique fondée sur le prototypage et les améliorations successives.
- Design Thinking : comprendre comment concevoir des solutions pédagogiques centrées sur les besoins des utilisateurs.
